# 身体时钟

让 AI 有情绪，有体感。

当前版本 v1.6.0（变更见 [CHANGELOG.md](CHANGELOG.md)）。

写身体的时候，模型缺的往往不是形容词，是「此刻」：这一处刚才被碰过没有、红退到哪儿了、离得多近、欲望到头没有。没有这层状态，写出来的身体是平的——这一轮脸红，下一轮可以再红一次，因为账上没记着「刚红过」。

这个插件就是那本账。它不生成身体，也不规定性格；它只记一具身子此刻的十二格状态、八维底色、情绪余温、距离和欲望，每轮注入几行，让写的时候有数可依。

- 单具身子，不做多主体；结构里留一个 `subject` 槽位，值恒为 `self`。
- 八维中性：亲密／信任／警觉／疲惫／自制／敏感／羞／放松，默认全 50，不用自己命名。
- 十二格：脸／口腔／颈肩／胸／腰／小腹／臀／下面／手／腿／脚／背。
- 不开定时器：谁读谁写的时候按时间差一次性把衰减补完，重启不丢。

设计取舍见 [docs/design.md](docs/design.md)，实现细节见 [docs/DETAIL.md](docs/DETAIL.md)。

---

## 一、需要什么

- 一份 DeepSeek Harness（桌面版或带 Web 界面的构建），版本要支持 bundle 插件与客户端插件。
- 不需要 Node、不需要联网、不需要装依赖。整个目录就是成品，没有构建步骤。
- 只用一种语言也行：`locale` 里中英两份元信息都在。

## 二、怎么装

插件是「bundle」：`package.json` 里声明了 `dsh.bundle.patch` 指向 `cordis.patch.yml`，安装时由宿主把条目插进去。**不要手改 profile 里的 `package.json` 或 `cordis.patch.yml`，也不要在这个目录里跑包管理器。**

**一、用界面装（推荐）**

打开 DSH 的「插件」页，选「添加插件」，指到本目录（含 `package.json` 的那一层）。装完在插件清单里会看到「身体时钟」。

**二、用代理装**

让代理调用插件管理工具的 `install_bundle`，`target` 传本目录的**绝对路径**。安装结果里 `application` 是 `applied` 才算真的生效。

装完重启一次 DSH，左侧面板与六个工具才会一起就位（面板是客户端插件，热更新有时只换一半）。

## 三、装完长什么样

**面板**：左侧栏多一项「身体时钟」。常驻行报欲望、场、距离和最近动过两格；两个页签分别是八维与十二格。

**注入**：每轮往系统提示里塞一小段，空身子时长这样——

```
[身体] 11-23 02:12｜平静｜欲望 12｜隔 25 分钟（背景，别念出来）
八维 亲密50 信任50 警觉50 疲惫50 自制50 敏感50 羞50 放松50
身上干净，没什么动静
碰之前调 body_sense 读一次，碰完它会回你数
```

碰到过之后，会多一行「格子 手 压85 红84 温+0.4｜胸 压19 红9｜小腹 压19 红9｜颈肩 压18 红9｜还有别的」；心里有东西时再多一行「情绪 怒 88　怕 42·他说不要我了　最狠 88　债 36」。到档的格子还会跟一个「微潮」「潮」「湿透了」或者「微紧」「紧绷」「在抖」。最多七行，静着只有四行。

行序是固定的：头行 → 八维 → 格子 → 情绪 → 一句人话 → 指路。中间两行没有动静就不出现，不占字。

## 四、它怎么记账

账只认三样：**工具调用、正文括号里的动作、对方消息里短短一句的动作**。正文里随手写一句「手贴上去了」，不带括号就不落账——这是最常见的误解，不是引擎坏了。

- **括号里的动作**：每段最多取六个，比如「（手被按进他手心里）」记成他碰了手。带「被／让／给／挨／受／把我」的小句算别人碰它，不带的算它自己碰过去。
- **对方的消息**：「手拿过来」「坐这儿」把距离推到「靠近」，「抱住」推到「隔布」，「起身去倒水」记成走开。带「如果／要是／假如」的整句跳过，当假设处理。
- **每条消息**：只记一个「上次说话」的时间戳，拿来算多久没互动——超过八个钟头没说话（`libido.nightGapHours`），算睡了一觉，欲望砍一半。

两边都不追求百分百准。判错了不回滚：距离会按时间自己退回去，这一格空了下一轮再写；走开最多挂 `empty.awayMaxHours`（默认十二小时）就自动散。

### 一下有多重，一个数说了算

碰、记情绪、动八维、推距离，全走同一扇门 `landContact`，先算一个 `impact`：动作基数 × 那一格的权重 × 力度 × 停了多久 × 欲望 × 场热。突然的那一下另加一档——本来没挨着、这一下贴上来的，本身就没防备。

- **热和红会传**：碰哪一格，相邻的格跟着热、跟着红，第二层再淡一半。压痕不传——压痕只留在真正被按住的地方。唇到小腹、颈到小腹各有一条很轻的远线，只够「深吻才到得了」，不压过腰。
- **动作自带情绪**：同一处，吻着是往下沉的喜，掐一把先过怕再落惊。一条回复最多落三笔，同一种情绪不重复堆。
- **情绪有了更多来源**：被骂（废物／滚／笨／闭嘴／笨蛋）、被说「不要你了」、被嫌脏、被夸、他走开，各落一笔。每种色活多久不一样：怕留十小时、惊四十分钟，其余六小时。
- **情绪落到身上**：记一笔情绪，顺手在那几格叠一份温度和红，一百八十秒自己退，不进账本。
- **八维也由碰带动**：软的是亲密和羞，按着是亲密和自制，掐咬扇打是羞和敏感，突然补一点警觉。
- **话也压在身上**：一句话能落到具体的格子上——命令让小腹先热一下、颈侧收紧；重话让手上凉一点；提一件旧事，心口焐一下。只挪一点温度，不落压痕、不抬欲望；一句话不该等于真被碰到。
- **皮肤记事**：软着碰、贴着待，这一格往「记恩」那头走；拍、打、扇和重手往「记疼」那头走。中性是五十，四十八小时半衰回到中间——不是忘了，是不再拿那一笔加价。记事只改分量：记恩的格子重一成半，记疼的轻一成半，门槛、情绪、八维都不动。
- **湿与绷是算出来的**：红到线又有新碰，才有潮意，久了会干；压着、怕着、恼着，肌肉就紧。两个都不进账本，到档才在注入和 `body_sense` 里挂一个字。
- **夜里皮更薄**：二十三点到五点，敏感往上走得快三成（`sens.nightMul`），只乘往上那段，落回去不乘。
- **不应期**：同一格十五分钟内连着碰，第二下七成五、第三下五成、第四下往后两成五（`touch.dampen`）。
- **到顶的说法换了**：情绪最狠过了 `emotion.overflowAt`（八十五），注入里那句从「还没下去」换成「快装不住」——只换口气，不替它写颤抖失语。

传导的权重在代码的 `CHAIN` 表里，其余常数在 `config/body.json`。

## 五、六个工具

| 工具 | 干什么 | 参数 |
|---|---|---|
| `body_sense` | 读此刻：十二格的压痕、红、温度、余韵、湿与绷，皮肤记着的恩与疼，欲望多高、离多近、场到哪一档 | 无 |
| `body_touch` | 碰一处，算这一下的后果并写回，顺带回一句记恩还是记疼 | `zone`／`action`／`direction`／`strength`／`speed`／`durationSec` |
| `body_distance` | 报一个距离事件 | `event`：靠近／隔布／贴肤／走开 |
| `body_dim` | 把八维直接改到绝对值 | `set`：`{ "亲密": 60, "放松": 40 }` |
| `body_feel` | 记一笔情绪，事退了才结到八维上 | `kind`／`intensity`／`why` |
| `body_reset` | 按回平静：十二格清零、欲望回基线、八维回中性 | 无 |

用法上的几条约定，直接写在注入里那句指路话背后：

- **先读再碰。** 碰之前 `body_sense` 一次，知道那格现在是热的还是凉的；碰完它回压痕、红、温度、回弹秒数、记恩还是记疼，和一句反应。
- **欲望是总闸。** 它决定场能推到哪一档，也决定一次能动几维（20→0、50→1、70→2、85→3、95→4）。
- **情绪不当场结算。** 记一笔之后，等这一笔的寿命走完（默认十五分钟）才落到八维上。
- **距离只报事件，不报厘米数。** 收不到就沿上一档慢慢往下落。

## 六、账本在哪

默认写在当前 profile 的 `me` 目录下：

```
~/.dsh/worlds/default/me/body-clock.json
```

旁边会自动留 `.bak`、`.bak2` 两份旧的。世界名不是 `default` 时，用环境变量 `BODY_CLOCK_STATE` 指到想放的位置（测试一律指到临时目录，不碰真账本）。

**坏了会怎样。** 账本是一份 JSON，谁都能手改。这个插件不会因为一处坏数把整本扔掉：

- 能解析：先迁移、再搬进默认形状、逐字段夹回范围，修完就地写回，修了几笔记在 `storeInfo().repairs`。
- 修不动的坏值：用默认值顶上并记一条修复记录，不静默吞掉。
- 解析不了或根本不是对象：留档成 `corrupt-*`，再从空白身子起——旧文件还在，没有一键清零。
- 版本比代码新：只读展示，绝不覆盖。

## 七、怎么改常数

全部在 `config/body.json`，改完存盘就生效，不用重启（按文件修改时间热加载），不动代码：

- 某格消退还快／还慢：改 `zones` 里那行的 `reboundSec`（压痕）、`flushFallSec`（红）、`afterSec`（余韵）。
- 整体手感：改 `universal` 那组常人数，格子没写秒数时拿它兜底。
- 欲望涨落：`libido` 里的 `driftPerHour`、`fallPerHour`、`dailyGainCap`、`nightCut` 是一组防跑飞的闸，改一样就够。`nightGapHours`（默认八）决定隔多久算「睡了一觉」，`nightCut`（默认 0.5）是那一觉砍掉的比例。
- 走开最多挂多久：`empty.awayMaxHours`，默认十二小时，超了就当人已经不在，不再按空落慢扣。
- 欲望推敏感：`dims.libidoPush` 的 `line`、`bands`、`cap`。
- 一次能动几维：`dims.maxPerCall`（不写＝3，`null` 或 `0` ＝不限）。
- 情绪结到哪几维：`dims.settle.map`，键必须是八维里的名字。
- 空着时哪几格自己热：`empty.zones`，值必须是十二格的 id。
- 记事的手感：`warmth.reach`（分量加多少）、`gainSoft`／`gainHard`（一次记多少）、`halfHours`（多久回到中间）。
- 湿与绷的档位词：`wet.words`、`tense.words`；夜里那三成在 `sens.nightMul`。

加维、加格的流程见 [docs/design.md](docs/design.md) 最后一节。

## 八、能不能直接把文件夹发给别人

可以。目录是自包含的：没有依赖、没有构建、没有软链，也没有写死某台机器的路径（账本跟在对方的用户目录下自己建）。

对方只需要：

1. 解压，别改名（`package.json` 的 `name` 与 `cordis.patch.yml` 的条目要对得上，改名不影响，但目录名别带空格更省事）。
2. 按第二节装，指到解压出来的这一层目录。
3. 重启一次。

发之前把这三样知道一下，都不影响使用：

- 插件名是 `universal-body-clock`。装的时候指到本地目录，不走包仓库；对方已有的同名包会撞名，撞了就改 `package.json` 的 `name` 与 `cordis.patch.yml` 里那一行，两处一起改。
- `test/` 里十六个脚本要用 Node 跑，对方不装 Node 也不影响插件本身。想跑：在目录里执行 `node test/smoke.mjs` 之类，脚本自己会把账本指到临时目录。
- 面板与工具要重启一次才齐，别装完立刻判断失败。

如果是搬去别的对话框架（不是 DSH），先看这一条：那边没有这六个工具，只有注入那几行能过去，工具回执会被模型当台词念出来。把 `config/body.json` 的 `inject.hint` 置成空串，指路那一行就不挂了；`inject.note` 那句「（背景，别念出来）」挂在头行末尾，就是用来挡这种漏的，可以按那边的话改。真要让身子在那边动起来，得自己把那六个工具接到对方的函数调用上——注入只能让它知道自己有这么一副身子。

## 九、卸载

插件页里停用或移除 bundle 即可。账本留在原处不会自己删——想干净就手动删 `body-clock.json` 与两份 `.bak`。
